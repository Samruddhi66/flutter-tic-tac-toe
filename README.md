# Tic Tac Toe (Flutter)

A tidy little Tic Tac Toe game built with Flutter and Material 3.

- ▶ **Play it in your browser:** https://samruddhi66.github.io/flutter-tic-tac-toe/
- ⬇ **Download the Android app (APK):** https://samruddhi66.github.io/flutter-tic-tac-toe/tic-tac-toe.apk

The APK is a personal build, so Android will ask you to allow installing from
your browser the first time. It runs on Android 5.0 and newer.

## How it plays

- Two modes: two players on one device, or one player against the computer
  (easy plays random moves, hard plays perfectly).
- You type both names and choose how many rounds (1–15) before the match starts.
- Every round is played; the score sits under each name and the match winner is
  declared only after the last round.
- Each win ends with a winner popup — "Next round" during the match, "Play
  again" at the end — and a draw gets its own popup.
- Winning lines light up with a short pulse, marks pop in, scores animate, and
  there are soft sound effects with a mute button in the app bar.
- Light and dark theme support.

## Project structure

```
lib/
  main.dart                 # Setup screen, game screen, scoreboard, winner popup
  game_logic.dart           # Pure Dart rules, match scoring and the computer AI
  sound/
    game_sound.dart         # Picks the right sound implementation
    game_sound_web.dart     # Web Audio tones for the browser
    game_sound_io.dart      # System sounds and haptics on phones
    game_sound_stub.dart    # Silent fallback
test/
  game_logic_test.dart      # Rules, match scoring and AI tests
  widget_test.dart          # Plays rounds through the UI
.github/workflows/deploy-web.yml  # Builds the web game and the APK, deploys both
```

## Running it

Install the [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.27 or
newer).

This repository contains the Dart source; the per-platform folders (`android/`,
`ios/`, `web/`, ...) are generated by Flutter itself. Create them once inside
the project folder:

```bash
flutter create . --project-name tic_tac_toe
```

Then run the game:

```bash
flutter pub get
flutter run           # pick a connected device or an emulator
```

To run in a browser instead:

```bash
flutter run -d chrome
```

## Tests and analysis

```bash
flutter analyze
flutter test
```

## Building releases

```bash
flutter build apk --release   # Android APK
flutter build web --release   # Web
```

Pushing to `main` sends the web game and the freshly built APK to GitHub Pages
through the workflow in `.github/workflows/deploy-web.yml`.
